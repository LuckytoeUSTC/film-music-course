## “未获取成功”具体指什么

指本次尝试把网站内容保存为本地原件时没有取得目标正文。它与“此前是否读过这篇文章”分开记录：此前可能通过检索工具读到正文或摘录，但这次直接下载被拒绝，因而没有相应的本地全文文件。

|情况|本次记录|意味着什么|
|---|---|---|
|服务器拒绝请求|8项返回403：Ebert、Criterion三项、奥斯卡两项、ResearchGate、Mix|网站拒绝这次程序请求；仅凭403不能确定是反爬、权限还是其他规则|
|连接未完成|Washington Post超时；ReelViews连接被关闭，共2项|本次网络请求失败，不代表文章不存在|
|拿到了网页，但没有目标正文|豆瓣4项仅返回安全检查／载入页；Apple Music两项跳转通用首页|存有HTML文件也不能算取得评论或曲目正文|

30项来源中，**4份PDF已保存，8份其他网页响应及文字提取已保存，6项只有载入页或错误目标页面，10项请求失败，另2项是既有本地资料。** 网页提取可能包含导航等内容，不能与精校全文等同。

所以，“所有参考资料都已登记”已经做到；“所有参考原文均已完整下载”尚未做到。此前将14份网页响应并列汇报，容易让人误以为都是有效原文，这里明确更正。失败项保留网址、错误与此前阅读范围，不用概述冒充原文。
